# Poster AI

A standalone public-facing product poster generator prototype.

## Current MVP

- Paste a product URL
- Simulate product analysis
- Select multiple product images
- Generate an AI-style poster preview
- Responsive, polished landing/workspace UI

## Next integration

Connect a permitted product-data source and an image-generation/design service to replace the demo product response with a real pipeline.

## Local development

```bash
npm install
npm run dev
```
